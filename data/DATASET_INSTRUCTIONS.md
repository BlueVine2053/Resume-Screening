# Original dataset (not redistributed)

Source: https://huggingface.co/datasets/cnamuangtoun/resume-job-description-fit

Download the `train.csv` and `test.csv` files from the dataset’s Files and versions tab, then save them as `data/train.csv` and `data/test.csv`. These files are excluded by `.gitignore`.

The included `sample_pairs.csv` is synthetic and not used to support the reported research results.
