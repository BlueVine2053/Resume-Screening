
# Intelligent Resume Screening and Job Matching System

## Project Overview

This project focuses on designing and implementing an intelligent resume screening and job matching system using Natural Language Processing (NLP).

The goal is to compare traditional keyword-based matching with semantic matching to determine how effectively NLP techniques can improve resume-to-job matching.

## Research Question

How effectively can NLP techniques improve resume-to-job matching compared with traditional keyword-based matching?

## Project Objectives

- Develop a keyword-based resume matching approach.
- Implement semantic matching using sentence embeddings.
- Calculate similarity scores between resumes and job descriptions.
- Compare the performance of both matching approaches.
- Evaluate the effectiveness of NLP techniques in resume screening.

## Proposed Technologies

- Python
- Pandas
- scikit-learn
- spaCy
- sentence-transformers
- Streamlit

## Matching Approaches

### Version 1: Keyword-Based Matching

Extract relevant keywords from resumes and job descriptions and calculate matching scores based on keyword overlap.

### Version 2: Semantic Matching

Generate sentence embeddings for resumes and job descriptions and calculate cosine similarity to identify semantic relationships.
